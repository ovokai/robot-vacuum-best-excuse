Entry for the make.fun competition "The Robot Vacuum's Best Excuse".
Running `main.ts` (Node, standard library only) writes the vacuum's
one-line excuse for missing a spot to `/output/entry.txt`:

> I didn't miss that corner. At 3% battery I checked my map and ran the numbers: the dock is home, and no crumb is worth dying for.
